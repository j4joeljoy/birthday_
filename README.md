# Birthday Surprise 🎂💗

A personalized, interactive birthday surprise website.

## 🚀 Live Demo

> Replace with your GitHub Pages URL after deploying:
> `https://YOUR-USERNAME.github.io/birthday/`

## ✨ Features

- 7 beautifully animated pages
- Dreamy pastel design with handwritten fonts
- Secret nickname gate
- Floating Polaroid photo surprise
- Scrapbook-style memories gallery
- Animated envelope with personal letter
- Three birthday wishes (with storage & export)
- Confetti explosion finale
- Friendship certificate
- Custom heart cursor, music toggle, and more

## 🛠 Setup

1. Edit `script.js` → `CONFIG` object at the top
2. Add photos to `assets/images/`
3. Add optional music to `assets/music/`
4. See `SETUP.md` for the full customization guide

## 📦 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch**
4. Select **main** branch, root folder
5. Click Save — your site will be live in ~1 minute!
